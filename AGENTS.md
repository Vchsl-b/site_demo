# Site project

- Repository: https://github.com/Vchsl-b/site_demo.git
- Branch: main. GitHub Pages publishing source: main / (root).
- The website entry point is index.html. Keep its styles embedded so the page also works when downloaded as a single file.
- When changing the CSS, keep style.css and the embedded stylesheet in index.html in sync.
- After requested site edits, check responsive layout and links, commit the relevant changes, and push to origin/main unless the user asks to keep the update local.
- Verify the matching GitHub Pages deployment before reporting that the live website has updated. Report a deployment failure or unavailable verification accurately.
- Preserve unrelated repository files. Keep preview screenshots out of Git.
